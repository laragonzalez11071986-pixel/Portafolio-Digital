# 📚 Biblioteca Digital UNTEC

## Descripción

Aplicación web desarrollada para gestionar libros y préstamos de una biblioteca.

## Tecnologías

* Java
* JSP
* Servlets
* JDBC
* MySQL
* JSTL
* Apache Tomcat

## Aprendizajes

Este proyecto me permitió aprender a desarrollar aplicaciones web con Java, trabajar con bases de datos MySQL y utilizar Servlets, JSP y JDBC.

## Proyecto académico

Desarrollado durante mi formación en desarrollo de software.
